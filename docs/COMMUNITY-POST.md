## Medium (if the group likes detail)

Gm everyone. Solo builder, sharing my ChainHack project.

**Prom It** turns any prompt into something you can buy over HTTP for cents of USDC, using x402 on Base Sepolia. No account, no card, no API key.

The problem is boring and real. Prompt libraries sell 300 dollar lifetime bundles because Stripe takes 30 cents plus 2.9 percent, so a 5 cent sale costs six times the price of the good. Bundling is the only shape that clears the fee.

What I care about is that it actually settled. In the receipt below, the signing buyer holds **0 ETH** and the address that paid the gas is the facilitator. A buyer paid USDC on chain without holding any ETH, because they signed a message instead of sending a transaction.

That is what makes agents interesting buyers. An agent wallet only needs stablecoin. Four surfaces share one payment client: browser, CLI, MCP server, Claude Code plugin.

Also shipped: a UUPS registry on Base Sepolia, source verified, with the settler role separated from the upgrade authority so a compromised backend cannot rewrite the contract.

Three things cost me hours and might save you some: the facilitator URL in the official x402 v2 READMEs is NXDOMAIN, the MCP TypeScript SDK was replaced on 27 July so every tutorial before August targets a dead API, and the facilitator labels a corrupted signature as an insufficient balance error. Ask me anything.

## If someone asks "why would an agent buy instead of writing its own prompt"

Because a paid listing carries a preview generated by running that exact prompt. You are paying for output you can see worked, not for text a model could improvise. That is the criterion the Claude Code skill reasons from.

Seed entries are their free tier, labelled free with per entry attribution. MotionSites co hosts ChainHack and the main track is about reselling prompts using x402, so Prom It is built as the resale layer rather than a competing storefront. Paid listings are original.
